1. บทนำระบบ Pro LPN Scanner

ระบบ **Pro LPN Scanner** พัฒนาขึ้นเพื่อช่วยบริหารคลังสินค้าและจัดส่งสินค้ารายสาขาอย่างแม่นยำ ช่วยให้พนักงานสามารถตรวจสอบบาร์โค้ด LPN คัดแยกกลุ่มตามสีกล่อง/สีถุง และบันทึกจัดส่งสินค้าขึ้นรถได้ถูกต้องรวดเร็ว โดยระบบทำงานร่วมกับเครื่องยิงบาร์โค้ดไร้สาย (Handheld Scanner) และรองรับการเก็บข้อมูลออฟไลน์ชั่วคราวเพื่อรับประกันว่าข้อมูลจะไม่หายแม้เน็ตช้า

คำแนะนำสำหรับผู้จัดทำ: เอกสารฉบับนี้เตรียมกรอบแบบเว้นพื้นที่ภาพประกอบไว้ เพื่อนรักสามารถสกรีนช็อตหน้าจอจริงของแต่ละหน้าขั้นตอนจากโปรแกรมมาแปะวางทับกรอบสี่เหลี่ยมด้านล่าง เพื่อให้คู่มือเล่มนี้มีความสมบูรณ์ที่สุด

2. การเข้าสู่ระบบ (Login Screen)

ขั้นตอนการยืนยันตัวตนพนักงานคลังสินค้า

1

เข้าสู่ URL ของระบบผ่านเว็บเบราว์เซอร์บนมือถือหรือเครื่อง Handheld

2

กรอกรหัสพนักงานในช่อง รหัสพนักงาน... (ตัวพิมพ์เล็กหรือใหญ่ก็ได้)

3

กดปุ่ม **เข้าสู่ระบบ** หรือกดปุ่ม **Enter** เพื่อยืนยันตัวตน ระบบจะตรวจสอบชื่อพนักงานผ่าน API อัตโนมัติ

ใส่ภาพหน้าจอล็อกอินที่นี่ ขนาดแนะนำ: 400 x 300px

3. เลือกงาน (Wave / Booking Selection)

การเลือกหรือสแกน Wave งานที่รถมารอรับสินค้า

1

สแกนหรือพิมพ์รหัส Wave หรือ รหัส Booking เพื่อเปิดดึงข้อมูลรายละเอียดใบงาน

2

หรือผู้ใช้งานสามารถกดปุ่ม **เลือกงาน** ในส่วนตาราง "รายการ Wave ทั้งหมด" ด้านล่างของจอภาพได้ทันที

3

หากโหลดข้อมูลเรียบร้อย ระบบจะแสดงข้อมูลรถ ทะเบียนรถ และยอดกล่องสินค้าที่ต้องส่งทั้งหมด

ใส่ภาพหน้าจอการเลือก Wave ที่นี่ ขนาดแนะนำ: 400 x 300px

4. เลือกสาขาที่จะสแกน (Branch Selection Dashboard)

หน้าจอตรวจสอบภาพรวมความคืบหน้าของสาขาทั้งหมดใน Wave

1

หน้าจอนี้จะลิสต์รายการรหัสสาขาและชื่อร้านค้าปลายทางทั้งหมดในใบงาน

2

ตัวเลขกำกับปุ่ม (เช่น **0/15**) บอกความคืบหน้า: **จำนวนที่สแกนสำเร็จ / จำนวนกล่องเป้าหมาย**

3

แตะเลือกที่สาขาที่ต้องการ เพื่อเข้าไปทำรายการสแกนบาร์โค้ดเช็กกล่องสินค้า

ใส่ภาพหน้าจอปุ่มเลือกสาขาที่นี่ ขนาดแนะนำ: 400 x 300px

5. การสแกนกล่อง/ถุงสี (Totes Scan)

การระบุประเภทสีกล่อง LPN รหัสที่ขึ้นต้นด้วย PR / PT / PN

1

สแกนรหัสกล่อง LPN บนหัวข้อ "สแกนบาร์โค้ด LPN กล่อง" ในระบบจะขึ้นป๊อปอัปให้ระบุสีของกล่อง/ถุง

2

กดเลือกสีตามสีจริงที่นับได้ (ดำ, น้ำเงิน, เหลือง, เขียว, แดง หรือ กล่องกระดาษ Reuse)

3

ระบบจะเริ่มต้นค่าเป็นจำนวน 1 เสมอ สามารถใช้ปุ่มตัวเลขที่แสดงบนจอ (Keypad) เพื่อแก้ไขหรือเพิ่มจำนวนกรณีมีมากกว่า 1 กล่องได้

ใส่ภาพหน้าจอป๊อปอัปเลือกสีและจำนวนที่นี่ ขนาดแนะนำ: 400 x 300px

6. การสแกนพาเลทหลัก (Pallet Scan)

การบันทึกจำนวนพาเลทสินค้า รหัสขึ้นต้นด้วย PP / SP

1

เมื่อสแกน LPN ขึ้นต้นด้วย **PP** หรือ **SP** ซึ่งเป็นพาเลทสินค้าขนาดใหญ่ ระบบจะนำเข้าสู่หน้ากรอกจำนวนโดยตรง

2

ระบบจะแสดงยอดเป้าหมายจากใบส่งของ ให้พนักงานนับยอดพาเลทที่พร้อมส่งแล้วระบุตัวเลขจริง

3

กด **ยืนยันยอด & บันทึก (Enter)** เพื่อทำรายการต่อไป

ใส่ภาพหน้าจอป๊อปอัปสแกน PP/SP ที่นี่ ขนาดแนะนำ: 400 x 300px

7. การรวมกล่องเข้าพาเลทหลัก (Combine Scan)

ฟังก์ชันจัดเซตกล่องย่อยบรรจุในพาเลทหลักเพื่อขึ้นส่งมอบสินค้า

1

เข้าสู่แท็บ **รวมกล่อง/พาเลท** ในหน้าสแกนหลัก

2

สแกน LPN ของพาเลทหลักก่อนในช่อง "1. สแกนพาเลทหลัก (Pallet/Tote)"

3

สแกนรหัสบาร์โค้ด LPN กล่องสินค้าที่บรรจุด้านในพาเลทนั้นเรื่อย ๆ จนครบ

4

เลือกระบุสีพาเลท และกดปุ่ม **ยืนยันการรวมกล่อง/พาเลท**

ใส่ภาพหน้าจอการทำงาน Combine ที่นี่ ขนาดแนะนำ: 400 x 300px

8. การปิดงานรายสาขาและจัดพิมพ์เอกสารใบคุม

ขั้นตอนสุดท้ายเพื่อยืนยันรายการจัดส่งสินค้าขึ้นรถและปริ้นใบควบคุมส่งสินค้า

1

เมื่อสแกนยอดกล่อง/พาเลทครบสมบูรณ์ของสาขานั้น ปุ่ม **ปิดจบงานสาขานี้** จะแสดงขึ้นมา

2

**กรณีกล่องหาย/ไม่พบ**: สามารถกด **บังคับปิดงาน** ระบบจะข้ามกล่องที่เหลือให้เป็นยอด 0 อัตโนมัติ (ขึ้นสถานะหาไม่พบ)

3

กดปุ่ม **ดู/พิมพ์เอกสารใบคุมส่งสินค้า** เพื่อเข้าหน้าใบ Transport Job และสั่งพิมพ์พิมพ์ออกเครื่องพิมพ์บาร์โค้ด/A4 ได้ทันที

ใส่ภาพตัวอย่างหน้าเอกสารใบคุม/พิมพ์ ที่นี่ ขนาดแนะนำ: 400 x 300px
